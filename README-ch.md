# 看見數字背後 · 台灣性侵害統計

[English](README.md) | 繁體中文

## 專案介紹

以繁體中文呈現台灣 2008 至 2025 年性侵害公開統計的互動網站。你可以查看年度趨勢、年齡與性別分布、2015–2025 年嫌疑人性別比例、被害人與加害人的關係，以及全台 22 縣市的比較。每張圖表都附有資料表，並提供 CSV 與 JSON 資料下載。

資料來自衛生福利部的性侵害統計與內政部的人口統計。被害人數與通報件數是不同的統計指標，這些資料也無法反映未通報的案件。

網站使用 TanStack Start、React 與 Vite+ 建置。設計決策、資料來源、統計方法、API 文件與部署方式請見 [DESIGN.md](DESIGN.md)。

## 開始使用

安裝 Node.js 22.12 或更新版本，接著在專案目錄執行：

```sh
npm ci
npm run dev
```

開啟終端機顯示的網址。預設使用連接埠 3000，若已被占用，開發伺服器會選擇其他可用的連接埠。

儲存庫已包含驗證過的資料。執行網站不需要外部 API、存取憑證、Python 或資料庫伺服器。

若要在本機建置並預覽正式版本：

```sh
npm run build
npm run preview
```

歡迎透過 issue 回報問題或提出修改建議。修改程式碼時，請建立分支，完成修改後執行以下檢查，再提交 pull request：


修改資料前，請先閱讀[資料維護說明](DESIGN.md#rebuild-or-refresh-the-data)。重新建置並驗證資料，檢查來源與品質報告的變更，並在 pull request 附上資料修正的來源依據。
